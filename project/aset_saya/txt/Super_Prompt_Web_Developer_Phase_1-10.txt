==================================================
PHASE 1 — SETUP PROJECT
==================================================

Buat project web modern menggunakan:
- Next.js
- React
- TypeScript
- Tailwind CSS

Aturan:
- Jangan membuat project baru jika project sudah ada.
- Gunakan App Router.
- Gunakan TypeScript.
- Gunakan Tailwind CSS.
- Siapkan struktur folder yang rapi.
- Pastikan project dapat dijalankan dengan npm run dev.
- Jangan menambahkan dependency yang tidak diperlukan.

Tujuan:
Membuat fondasi project yang bersih dan siap dikembangkan.

Output:
1. Struktur folder.
2. Command instalasi.
3. File yang dibuat/diubah.
4. Source code lengkap.
5. Cara menjalankan project.
6. Self-check error TypeScript dan build.
