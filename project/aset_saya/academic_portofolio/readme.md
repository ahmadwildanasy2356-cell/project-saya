# Ahmad Wildan — Academic Portfolio

> **International Academic Portfolio Website**  
> **Premium · Editorial · Multilingual · Fully Responsive · Chatbot-Powered**

Website portofolio akademik premium untuk **Ahmad Wildan Asy Syifa**, dirancang khusus untuk keperluan pendaftaran universitas luar negeri, beasiswa, internship, freelance, networking profesional, personal branding, dan peluang kerja internasional.

Dibangun sepenuhnya dengan **HTML5, CSS3, dan JavaScript Vanilla** tanpa framework, tanpa library eksternal, tanpa build tool. Cukup buka `index.html` di browser — langsung berjalan.

## 🌟 Gambaran Umum

Website ini dirancang untuk memenuhi kebutuhan **personal branding akademik internasional**. Desainnya menggabungkan estetika editorial premium dengan nuansa akademik modern. Setiap elemen — dari tipografi hingga interaksi mikro — dipilih untuk menciptakan kesan profesional, terpercaya, dan berkelas.

Target audiens:
- Admissions officer universitas luar negeri
- Komite beasiswa
- Recruiter internship/kerja internasional
- Klien freelance
- Jaringan profesional global
- Siapa pun yang ingin mengenal Ahmad Wildan secara mendalam

Website ini **bukan** template portofolio programmer pada umumnya, melainkan **portofolio akademik** yang menonjolkan perjalanan pendidikan, kompetensi bahasa, pencapaian, dan arah pengembangan internasional.

## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🌐 **6 Bahasa** | Indonesia, English, العربية (RTL), 中文, 한국어, 日本語 — lengkap dengan pergantian arah teks (LTR/RTL) |
| 🌙 **Dark Mode** | Toggle tema gelap/terang dengan penyimpanan preferensi di localStorage |
| 📱 **Responsive** | Optimal pada 320px hingga 1920px+ |
| ♿ **Aksesibilitas** | Semantic HTML, ARIA, keyboard navigation, skip link, reduced motion |
| 🔍 **SEO** | Meta tags, Open Graph, Twitter Card, JSON-LD structured data |
| 📊 **Animasi Angka** | Counter halus saat elemen statistik muncul di viewport |
| 🎨 **Reveal Animation** | IntersectionObserver untuk animasi scroll yang halus |
| 📜 **Timeline Pendidikan** | Visual editorial untuk perjalanan akademik |
| 📜 **Gallery Sertifikat** | Grid premium dengan modal preview, keyboard support |
| 🤖 **Chatbot "Wildan AI"** | Asisten akademik lokal, knowledge base, typing indicator, localStorage |
| 📝 **Formulir Kontak** | Web3Forms, validasi real-time, loading state |
| 📄 **CV Eksternal** | Tombol menuju CV online di tab baru |
| 🎯 **No Frameworks** | Murni HTML + CSS + JavaScript Vanilla |
